# beadpix — 终端高分辨率像素项目

用半块字符 `▀`（前景色=上像素、背景色=下像素）把终端变成真彩色像素画布，
配合差分渲染实现高帧率不闪烁的输出。一个共用引擎，两个应用。

```
crates/
├── beadpix/   核心渲染引擎（画布、半块差分渲染器、精灵/调色板、终端管理）
├── garden/    终端花园挂机游戏
└── face/      高帧率数字人脸
```

## 运行

需要 [Rust 工具链](https://rustup.rs)。建议在 Windows Terminal 中运行（完整 24-bit 真彩支持）。

```sh
cargo run --release -p garden   # 花园
cargo run --release -p face     # 人脸
```

## garden — 花园挂机游戏

- 种下种子，植物随**真实时间**生长（关掉游戏也在长，重开自动结算离线进度）
- 每株花有基因：花色（HSV 色相/饱和度）、花型、株高、生长速度
- 相邻两株盛开的花可以**杂交**，基因混合 + 突变，稀有花型只能靠杂交解锁
- 天气系统：晴 / 雨（生长 1.6x + 雨滴粒子）/ 雾 / 夜晚（星星 + 萤火虫），全屏光照染色
- 存档：退出时写入 `garden_save.json`

按键：`←/→` 选地块 · `Enter` 播种 · `H` 收获 · `X` 杂交（当前块与右侧块）· `Esc` 存档退出

## face — 数字人脸

- 60fps 目标帧率，差分渲染只重绘变化像素
- 参数化脸模型：眼睑开合、眉毛高度/倾角、嘴角曲线、张嘴、腮红、瞳孔缩放
- 六种情绪之间平滑插值：平静 / 开心 / 惊讶 / 悲伤 / 愤怒 / 困倦
- 自主行为：随机眨眼、视线漂移、呼吸起伏——不操作它也是活的
- 说话模式：嘴部按节奏开合

按键：`1-6` 切换情绪 · `方向键` 手动控制视线 · `空格` 交还自主视线 · `T` 说话开关 · `R` 切换渲染器 · `Esc` 退出

默认使用**混合渲染器**（见下），按 `R` 可切回纯半块模式对比效果。

## 引擎要点（beadpix）

- `Canvas`：与终端无关的 RGB 像素缓冲，逻辑分辨率 = 终端列数 × 行数×2
- `HalfBlockRenderer`：每帧与上一帧逐格比较，只输出变化格子的光标移动 + 颜色转义，
  并合并连续的颜色/位置状态，静态画面几乎零带宽
- `HybridRenderer`：画布分辨率翻到 列数×2 × 行数×4，每个字符格（2×4=8 像素）
  逐格在两种表示间择优：平滑区域用半块 `▀` 保两种独立真彩，高对比轮廓用
  盲文点阵 `⣿` 提 4 倍空间密度（灵感来自 HelloGitHub 第 119 期的 pokemon-tbje，
  它用纯盲文点阵渲染宝可梦精灵）。判据 = 两种表示重建原像素的色彩误差取最小
- `Sprite`/`Palette`：ASCII 字面量定义的索引色精灵，换调色板即换色（花卉杂交变色的基础）
- `TerminalSession`:备用屏幕 + raw mode 守卫，Drop 时自动恢复终端
