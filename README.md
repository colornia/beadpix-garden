# beadpix · 花园

一座运行在终端里的像素花园。用半块字符 `▀`（前景色=上像素、背景色=下像素）
把终端变成真彩色画布，配合逐光源 2D 光照与连续昼夜，养一座会呼吸的花园。

```
crates/
├── beadpix/   像素渲染引擎（画布、半块差分渲染、精灵/调色板、终端管理）
└── garden/    花园挂机游戏
```

> 引擎 `beadpix` 与[数字人脸项目](https://github.com/colornia/beadpix-face)同源，
> 两边各自持有一份副本，可独立演进。

## 运行

需要 [Rust 工具链](https://rustup.rs)。建议在 Windows Terminal 中运行（完整 24-bit 真彩支持）。

```sh
cargo run --release -p garden            # 正常挂机节奏
cargo run --release -p garden -- --fast  # 测试模式：生长与昼夜 20 倍速
```

## 玩法

**设计骨架**：治愈系外壳 + 育种脊椎。地块稀缺造出「决定」，遗传可视造出「意图」，
离线日记 + 软照料造出「回访」，委托造出「永不通关」——全程无死亡、无损失、可随时离开。

- 植物随**真实时间**生长（关掉游戏也在长）。回来先看「你不在时发生了什么」日记：
  流星掠过改了某株的花色、野蜂替你授了粉、旅人留下一颗种子
- **有限地块**：开局 5 块，退役盛开的植株换堆肥、堆肥换扩张（最多 16 块）。
  稀有科系堆肥产出更高——留着看还是换地，是你自愿的取舍
- **遗传预览**：相邻两株盛开时显示子代色相弧段／株高区间／发光概率，
  可 `P` 钉住目标表型做定向育种；每次杂交自动记入育种笔记
- **活力**：疏于照料只让植株垂头、光变暗，浇水即复原——**植物永不死亡**，
  每天来一次的玩家永远看不到蔫
- **委托**：每周轮换三档目标表型（园丁的心愿 → 植物学者的订单 → 收藏家的执念），
  达成换堆肥与稀有种。图鉴集齐只是开场
- **植物是角色不是调色板**：眼球花会眨眼、触手藤让邻株枯萎、曼德拉草夜间滋养邻居、
  月见花只在夜里绽放、日晷花追着天体转——摆放位置与来访时刻本身就是谜题
- **古株**：活满 6 小时的植株生出苔痕虬枝，此后每 2 小时无偿结籽——
  堆肥它能换地，留着它则细水长流。这份拉扯是自愿的，不是惩罚
- 天气：晴／雨／雾叠加在连续昼夜之上；彩虹、流星、雁群、蝴蝶、萤火虫、飘落花瓣
- 存档：退出时写入 `garden_save.json`（向后兼容）

按键：`←→↑↓` 选地块 · `Enter` 播种 · `W` 浇水 · `H` 收获 · `X` 杂交 · `P` 钉目标 ·
`C` 退役堆肥 · `E` 扩张 · `Q` 委托 · `B` 图鉴 · `Esc` 存档退出

## 品种

六大科系 17 品种 × 8 色系 = 136 格图鉴：

| 科系 | 品种 | 获取 |
|---|---|---|
| 花卉 | 圆瓣 · 四瓣 · 星芒 · 重瓣 | 野生／杂交 |
| 草蕨 | 芒草 · 蕨叶 | 野生（草甸／林间） |
| 水生 | 海葵 · 珊瑚 | 深海群系野生 |
| 异界 | 眼球花 · 触手藤 | 杂交突变 2.5% |
| 炼金 | 曼德拉草 · 贤者金花 | 杂交突变 2.5% |
| 天时 | 月见花 · 日晷花 · 雷纹花 · 昙花 | 杂交突变 2% |
| 天时 | **陨星花** | 只有流星落进花园才会留下 |

图鉴按稀有度**分层展示**（顶部色带：灰=常见／蓝=角色／金=传说）。
底纹层是墙纸，正是它的平凡衬出稀有；角色层每个是一次发现；
传说层得制造条件或定向育出，每个是一个故事。

几株"得赶上那一刻"的：

- **雷纹花**：种下后不下雨就一直是颗种子，等到雨来才发芽，雨中花瓣迸发电弧
- **月见花／昙花**：白天只是闭合的花苞，入夜才绽放
- **昙花**：全局唯一会谢的品种——开一夜，天明即谢。花苞期 HUD 就会预告，
  谢时留下 2-3 颗种子（净赚）。会失去的只有"亲眼看着它开"这件事

## 引擎要点（beadpix）

- `Canvas`：与终端无关的 RGB 像素缓冲，逻辑分辨率 = 终端列数 × 行数×2
- `HalfBlockRenderer`：每帧与上一帧逐格比较，只输出变化格子的光标移动 + 颜色转义，
  并合并连续的颜色/位置状态，静态画面几乎零带宽
- `HybridRenderer`：每个字符格 2×4=8 像素，逐格在半块与盲文点阵间择优
  （平滑区保真彩、高对比轮廓提 4 倍密度）。人脸项目在用，花园暂用纯半块
- 光照贴图：环境光打底，逐光源线性衰减叠加，最后逐像素相乘——
  每朵花都是真实光源，在草地上投出自己颜色的光池
- `Sprite`/`Palette`：ASCII 字面量定义的索引色精灵，换调色板即换色（杂交变色的基础）
- `TerminalSession`：备用屏幕 + raw mode 守卫，Drop 时自动恢复终端
